# ADR-0001: Own implementation, no MDM

- **Status:** Accepted
- **Date:** not recorded (before 2026-11-22)

## Context

We need to manage our Meta Quest headsets at the arena. Ready-made tools exist (MDM = a product that manages many devices).

## Decision

Write our own system. Do not use and do not suggest ready-made MDM tools.

## Consequences

- **Checked by:** no automatic check. It is a product rule.

## Alternatives considered

ManageXR, ArborXR and similar tools: rejected. The reason is not recorded.
