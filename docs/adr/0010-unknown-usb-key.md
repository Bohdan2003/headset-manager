# ADR-0010: Never approve the USB debugging dialog with an unknown key

- **Status:** Accepted
- **Date:** not recorded (before 2026-11-22)

## Context

An approved key opens the headset for the computer that owns it.

## Decision

Never approve the USB debugging dialog for an unknown key.

## Consequences

- A stranger's computer can't get access.
- **Checked by:** no automatic check. It depends on the person in the headset.

## Alternatives considered

Not recorded.
