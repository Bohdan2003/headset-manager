# ADR-0021: Everything in English

- **Status:** Accepted
- **Date:** UI 2026-11-04, the rest 2026-11-22

## Context

The interface, docs, comments and commits need one language.

## Decision

Write the UI, docs, comments, commits and chat replies in simple English (B1 with a little B2). Use the terms headset, Protection, Sleep, Request access. Translate old Russian comments only in files you edit anyway.

## Consequences

- Old Russian comments stay for some time.
- **Checked by:** no automatic check. `reviewer` looks for it in the diff.

## Alternatives considered

Not recorded.
